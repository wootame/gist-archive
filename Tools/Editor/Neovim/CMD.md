# nvim コマンド・操作リファレンス

## 起動

**ファイルを開く**
```bash
nvim <file>
```

**複数ファイルを開く**
```bash
nvim <file1> <file2>
```

**指定行から開く**
```bash
nvim +120 <file>
```

**パターン検索して開く**
```bash
nvim +/ERROR <file>
```

## モード切り替え

**ノーマルモードに戻る**
```
Esc
```

**挿入モードに入る（カーソル前）**
```
i
```

**挿入モードに入る（カーソル後）**
```
a
```

**行頭で挿入**
```
I
```

**行末で挿入**
```
A
```

**新しい行を下に追加**
```
o
```

**新しい行を上に追加**
```
O
```

## 保存・終了

**保存**
```
:w
```

**終了**
```
:q
```

**保存して終了**
```
:wq
```

**強制終了（保存しない）**
```
:q!
```

**すべて保存して終了**
```
:wa | qa
```

## 移動

**行頭 / 行末**
```
0 / $
```

**単語移動（次 / 前）**
```
w / b
```

**ファイル先頭 / 末尾**
```
gg / G
```

**指定行へ移動**
```
:<line>
```

## 編集

**1文字削除**
```
x
```

**単語削除**
```
dw
```

**行削除**
```
dd
```

**1行コピー**
```
yy
```

**貼り付け（後 / 前）**
```
p / P
```

**元に戻す / やり直し**
```
u / Ctrl + r
```

## 検索・置換

**前方検索**
```
/pattern
```

**次 / 前のヒットへ移動**
```
n / N
```

**ファイル全体を置換**
```
:%s/old/new/g
```

**確認しながら置換**
```
:%s/old/new/gc
```

## 複数ファイル操作

**バッファ一覧**
```
:ls
```

**次 / 前のバッファへ移動**
```
:bnext / :bprev
```

**指定バッファへ移動**
```
:buffer <番号>
```

**垂直分割 / 水平分割**
```
:vsplit / :split
```

**ウィンドウ移動**
```
Ctrl + w, h/j/k/l
```

## PowerShell 連携例

**PowerShell からファイルを開く**
```powershell
nvim "C:\path\to\file.txt"
```

**Select-String のヒット行を開く**
```powershell
$hit = Select-String -Path "C:\path\to\source.txt" -Pattern "ERROR" | Select-Object -First 1
if ($hit) { nvim +$($hit.LineNumber) $hit.Path }
```

**Git 管理ファイルをまとめて開く（ファイル数が多い場合に注意）**
```powershell
nvim $(git ls-files)
```
