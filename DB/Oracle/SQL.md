# Oracle SQL リファレンス

## セッション・コンテキスト

**現在ユーザー確認**
```sql
show user
```

**現在スキーマ確認**
```sql
select sys_context('USERENV', 'CURRENT_SCHEMA') from dual;
```

**現在コンテナ確認（CDB/PDB）**
```sql
show con_name
```

## DDL（定義）

**テーブル作成**
```sql
create table users (
  id number generated by default as identity primary key,
  name varchar2(100) not null,
  email varchar2(255) unique,
  created_at timestamp default systimestamp not null
);
```

**テーブル変更（列追加）**
```sql
alter table users add (status varchar2(20) default 'active' not null);
```

**テーブル名変更**
```sql
rename users to app_users;
```

**テーブル削除**
```sql
drop table app_users purge;
```

## DML（操作）

**INSERT**
```sql
insert into users (name, email) values ('Taro', 'taro@example.com');
```

**複数行 INSERT（INSERT ALL）**
```sql
insert all
  into users (name, email) values ('Hanako', 'hanako@example.com')
  into users (name, email) values ('Jiro', 'jiro@example.com')
select 1 from dual;
```

**UPDATE**
```sql
update users
   set status = 'inactive'
 where email = 'taro@example.com';
```

**DELETE**
```sql
delete from users where status = 'inactive';
```

**MERGE（UPSERT）**
```sql
merge into users u
using (select 1 id, 'Taro' name, 'taro@example.com' email from dual) src
   on (u.id = src.id)
 when matched then
   update set u.name = src.name, u.email = src.email
 when not matched then
   insert (id, name, email) values (src.id, src.name, src.email);
```

## SELECT 基本

**全件取得**
```sql
select * from users;
```

**条件検索**
```sql
select id, name, email
  from users
 where status = 'active';
```

**並び替え**
```sql
select id, name, created_at
  from users
 order by created_at desc;
```

**件数取得**
```sql
select count(*) as total from users;
```

## JOIN / 集計

**INNER JOIN**
```sql
select u.id, u.name, o.order_no, o.total_amount
  from users u
  join orders o on o.user_id = u.id;
```

**GROUP BY + HAVING**
```sql
select user_id, count(*) order_count, sum(total_amount) total_amount
  from orders
 group by user_id
having count(*) >= 3;
```

## 日付・文字列

**現在日時**
```sql
select systimestamp from dual;
```

**日付加算**
```sql
select created_at, created_at + interval '7' day as plus_7d
  from users;
```

**文字列結合**
```sql
select name || ' <' || email || '>' as label
  from users;
```

## 便利クエリ（管理系）

**テーブル一覧（自分のスキーマ）**
```sql
select table_name from user_tables order by table_name;
```

**列情報確認**
```sql
select column_name, data_type, nullable
  from user_tab_columns
 where table_name = upper('users')
 order by column_id;
```

**実行中セッション確認**
```sql
select sid, serial#, username, status, machine
  from v$session
 where username is not null;
```

## トランザクション

**コミット**
```sql
commit;
```

**ロールバック**
```sql
rollback;
```

**セーブポイント**
```sql
savepoint sp_before_update;
```

**セーブポイントまで戻す**

rollback to sp_before_update;
