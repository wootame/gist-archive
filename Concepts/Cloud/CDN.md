# CDN (Content Delivery Network)

コンテンツ配信ネットワークサービス。世界中のエッジロケーションからコンテンツを高速配信し、レイテンシーを低減。セキュリティ機能も統合されていることが多い。

## 主要サービス

### Cloudflare CDN
グローバルCDNとセキュリティサービス。無料プランあり、DDoS保護。

**特徴:**
- グローバル200+ロケーション
- DDoS保護
- WAF (Web Application Firewall)
- SSL/TLS証明書
- キャッシュ最適化
- 無料プランあり

**ユースケース:**
- Webサイト高速化
- DDoS攻撃対策
- グローバルコンテンツ配信
- API保護

### AWS CloudFront
AWSのCDNサービス。AWS統合とエッジロケーション。

**特徴:**
- グローバル200+エッジロケーション
- AWSサービス統合 (S3, EC2, ELB)
- Lambda@Edge
- リアルタイムログ
- セキュリティヘッダー

**ユースケース:**
- AWSベースのアプリケーション
- グローバル配信
- エッジコンピューティング
- ライブストリーミング

### Fastly
リアルタイムCDN。エッジコンピューティング機能。

**特徴:**
- エッジコンピューティング
- リアルタイム設定変更
- 詳細なログと分析
- イメージ最適化
- ストリーミング対応

**ユースケース:**
- パフォーマンス重視の配信
- エッジ処理
- リアルタイムコンテンツ
- ストリーミングサービス

### Akamai
老舗のCDNプロバイダー。エンタープライズ向け。

**特徴:**
- グローバル4000+サーバー
- エンタープライズセキュリティ
- メディア配信最適化
- DDoS保護
- クラウドセキュリティ

**ユースケース:**
- 大規模エンタープライズ
- メディア・エンターテイメント
- 金融サービス
- 政府機関

### Bunny CDN
コストパフォーマンスに優れたCDN。シンプルな料金体系。

**特徴:**
- 競争力のある価格
- グローバル100+ロケーション
- ストリーミング対応
- イメージ最適化
- 詳細な統計

**ユースケース:**
- コスト重視の配信
- スタートアップ
- 個人プロジェクト
- ストリーミングコンテンツ
