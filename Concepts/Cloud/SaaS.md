# SaaS (Software as a Service)

完成されたソフトウェアをインターネット経由で提供するサービス。ユーザーはソフトウェアを購入・インストールする必要なく、ブラウザやAPI経由で利用できる。

**関連メモ:**
- Git / GitHub の実操作は [Operations/VersionControl/Git/CMD.md](../../Operations/VersionControl/Git/CMD.md)

## 開発・DevOps

### GitHub
コード管理とコラボレーションプラットフォーム。開発チームの中心的なツール。

**操作メモ:**
- 実務コマンド集: [Operations/VersionControl/Git/CMD.md](../../Operations/VersionControl/Git/CMD.md)

**特徴:**
- Gitベースのバージョン管理
- プルリクエストとコードレビュー
- GitHub ActionsによるCI/CD
- Issue管理とプロジェクト管理
- GitHub Packages (パッケージレジストリ)

**ユースケース:**
- オープンソースプロジェクト
- チーム開発
- コードレビュープロセス

### GitLab
DevOpsプラットフォーム。Git、CI/CD、セキュリティスキャンを統合。

**特徴:**
- 完全なDevOpsライフサイクル
- 組み込みCI/CD
- セキュリティスキャンとコンプライアンス
- セルフホスティング可能
- 高度なプロジェクト管理

**ユースケース:**
- エンタープライズDevOps
- セキュリティ重視の開発
- コンプライアンス要件

### Bitbucket
Atlassianのコード管理サービス。Jira連携が強力。

**特徴:**
- Git/Mercurial対応
- Jiraとの深い統合
- PipelinesによるCI/CD
- ブランチ権限管理
- プルリクエストテンプレート

**ユースケース:**
- Atlassianエコシステム
- エンタープライズ開発
- プロジェクト管理重視

### CircleCI
継続的インテグレーション/デリバリーサービス。高速なビルドとデプロイを提供。

**特徴:**
- 高速なビルド実行
- Dockerネイティブ
- 柔軟なワークフロー
- 詳細なテストレポート
- セキュリティスキャン

**ユースケース:**
- 高速なCI/CDパイプライン
- マイクロサービス
- クラウドネイティブ開発

### Jenkins (Cloud)
オープンソースのCI/CDツール。豊富なプラグインと拡張性。

**特徴:**
- オープンソース
- 2000以上のプラグイン
- 分散ビルド
- パイプラインas Code
- クラウド対応

**ユースケース:**
- カスタムCI/CDワークフロー
- レガシーシステム統合
- 大規模開発チーム

### Travis CI
GitHub連携に特化したCI/CDサービス。オープンソースプロジェクト向け無料枠。

**特徴:**
- GitHub統合
- 無料枠 (オープンソース)
- 複数言語対応
- マトリックスビルド
- デプロイメント統合

**ユースケース:**
- オープンソースプロジェクト
- GitHubベースの開発
- シンプルなCI/CD

## 監視・ログ管理

### Datadog
包括的な監視・分析プラットフォーム。インフラ、アプリ、ログの統合監視。

**特徴:**
- インフラ監視
- APM (Application Performance Monitoring)
- ログ管理
- ダッシュボードとアラート
- 機械学習による異常検知

**ユースケース:**
- エンタープライズ監視
- マイクロサービス監視
- クラウドインフラ管理

### New Relic
アプリケーションパフォーマンス監視(APM)。フルスタック可観測性。

**特徴:**
- APMとインフラ監視
- ログ管理
- 合成監視
- エラー追跡
- ビジネスインテリジェンス

**ユースケース:**
- パフォーマンス最適化
- ユーザーエクスペリエンス監視
- ビジネスメトリクス分析

### Sentry
エラートラッキングと監視サービス。リアルタイムエラー通知。

**特徴:**
- リアルタイムエラー追跡
- パフォーマンス監視
- リリース追跡
- 複数言語対応
- インテグレーション豊富

**ユースケース:**
- エラー監視
- パフォーマンス最適化
- リリース管理

### Grafana Cloud
可視化・監視プラットフォーム。メトリクス、ログ、トレース。

**特徴:**
- ダッシュボード作成
- 複数データソース対応
- アラート機能
- ログ集約
- トレース可視化

**ユースケース:**
- メトリクス可視化
- ログ分析
- オブザーバビリティ

### Splunk
ログ管理と分析プラットフォーム。セキュリティ情報イベント管理(SIEM)。

**特徴:**
- 大規模ログ処理
- SIEM機能
- 機械学習分析
- セキュリティ脅威検知
- コンプライアンスレポート

**ユースケース:**
- セキュリティ監視
- コンプライアンス
- 大規模ログ分析

### LogDNA/Mezmo
ログ管理サービス。リアルタイムログ集約と分析。

**特徴:**
- リアルタイムログ集約
- 高度な検索とフィルタリング
- アラート機能
- アーカイブとコンプライアンス
- 複数ソース対応

**ユースケース:**
- ログ分析
- トラブルシューティング
- コンプライアンス監視

## データベース・ストレージ

### MongoDB Atlas
フルマネージドMongoDBサービス。マルチクラウド対応。

**特徴:**
- グローバルクラスタ
- 自動スケーリング
- バックアップと復元
- パフォーマンス監視
- セキュリティ機能

**ユースケース:**
- NoSQLデータベース
- クラウドネイティブアプリ
- リアルタイム分析

### PlanetScale
MySQLベースのサーバーレスデータベース。ブランチング機能。

**特徴:**
- サーバーレススケーリング
- データベースブランチング
- 非破壊的スキーマ変更
- グローバルリードレプリカ
- 組み込みバックアップ

**ユースケース:**
- スケーラブルなWebアプリ
- マイクロサービス
- 開発ワークフロー改善

### Airtable
スプレッドシートとデータベースのハイブリッド。ノーコードでのアプリ構築。

**特徴:**
- スプレッドシートインターフェース
- リレーショナルデータベース機能
- APIアクセス
- 自動化機能
- テンプレート豊富

**ユースケース:**
- ノーコードアプリケーション
- プロジェクト管理
- データ収集・管理

### Notion
ドキュメント・プロジェクト管理。データベース機能内蔵。

**特徴:**
- ドキュメント作成
- データベース機能
- プロジェクト管理
- コラボレーション
- APIとインテグレーション

**ユースケース:**
- ナレッジ管理
- プロジェクト管理
- チームコラボレーション
