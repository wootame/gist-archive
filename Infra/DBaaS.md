# DBaaS (Database as a Service)

マネージドデータベースサービス。データベースのセットアップ、運用、メンテナンスをクラウドプロバイダーが担当し、ユーザーはデータ操作に集中できる。

## 主要サービス

### AWS RDS
リレーショナルデータベースサービス。MySQL、PostgreSQL、Oracle、SQL Server対応。

**特徴:**
- 自動バックアップ
- 自動フェイルオーバー (Multi-AZ)
- リードレプリカ
- 自動スケーリング (Aurora)
- パフォーマンスインサイト

**ユースケース:**
- Webアプリケーション
- エンタープライズデータベース
- 分析ワークロード
- ハイブリッドクラウド

### AWS DynamoDB
フルマネージドNoSQLデータベース。ミリ秒単位の高速レスポンス。

**特徴:**
- キーバリューおよびドキュメントモデル
- 自動スケーリング
- グローバルテーブル
- ストリーム機能
- DAX (インメモリキャッシュ)

**ユースケース:**
- リアルタイムアプリケーション
- IoTデータ
- セッションデータ
- ゲームデータ

### Google Cloud SQL
マネージドRDBMSサービス。MySQL、PostgreSQL対応。

**特徴:**
- 自動バックアップと復元
- 高可用性構成
- リードレプリカ
- 自動スケーリング
- Cloud SQL Proxy

**ユースケース:**
- Webアプリケーション
- モバイルバックエンド
- 分析データベース
- レガシーアプリケーション移行

### Google Firestore
NoSQLドキュメントデータベース。リアルタイム同期機能。

**特徴:**
- ドキュメント指向
- リアルタイムリスナー
- オフライン対応
- 自動スケーリング
- セキュリティルール

**ユースケース:**
- モバイルアプリケーション
- リアルタイムコラボレーション
- ユーザー生成コンテンツ
- IoTデータ

### Azure Cosmos DB
グローバル分散型NoSQLデータベース。複数のAPIモデル対応。

**特徴:**
- マルチモデル (SQL, MongoDB, Cassandra, Gremlin, Table)
- グローバル分散
- 自動スケーリング
- 99.999% SLA
- 変更フィード

**ユースケース:**
- グローバルアプリケーション
- IoTとテレメトリ
- リアルタイム分析
- マイクロサービス

### Neon
サーバーレスPostgreSQL。ブランチング機能とスケールtoゼロ。

**特徴:**
- サーバーレススケーリング
- データベースブランチング
- 自動スケールtoゼロ
- PostgreSQL互換
- 組み込みバックアップ

**ユースケース:**
- 開発・テスト環境
- サーバーレスアプリケーション
- マイクロサービス
- スタートアップ

### CockroachDB
分散SQLデータベース。PostgreSQL互換。

**特徴:**
- 分散アーキテクチャ
- ACIDトランザクション
- PostgreSQL互換
- 自動スケーリング
- 地理的分散

**ユースケース:**
- グローバルアプリケーション
- 高可用性要件
- 分散システム
- クラウドネイティブ

### Redis Cloud
マネージドRedisサービス。キャッシュとデータストア。

**特徴:**
- Redis互換
- 自動バックアップ
- 高可用性
- グローバル分散
- モジュール対応 (RedisJSON, RediSearch)

**ユースケース:**
- キャッシュレイヤー
- セッションストア
- リアルタイム分析
- メッセージング
